# Part 4: Linux Security & Hardening

This part covers how to protect Linux systems: the security model, hardening, identity and access control, mandatory access control, auditing, cryptography, secrets, and vulnerability management.

| Chapter | Title | What you will learn |
|---------|-------|---------------------|
| 14 | [Linux Security Fundamentals](14-security-fundamentals/README.md) | Security architecture, least privilege, patching, hardening, permissions, isolation, Secure Boot |
| 15 | [Authentication, Authorization & Identity Management](15-authentication-and-identity/README.md) | PAM, NSS, passwords, sudo, SSH keys, MFA, LDAP, Active Directory, SSSD |
| 16 | [Mandatory Access Control, Auditing & Security Monitoring](16-mac-auditing-and-monitoring/README.md) | SELinux, AppArmor, auditd, AIDE, log analysis, cryptography, TLS, secrets, vulnerability assessment |

> [!NOTE]
> Treat this part as a starting point. Compare it with your organization's policy, current vendor documentation, and benchmarks (CIS, DISA STIG) before changing production systems.
