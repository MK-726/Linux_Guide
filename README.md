# Linux Guide

A practical Linux handbook and cheatsheet for system administrators, DevOps engineers, infrastructure engineers, and advanced Linux users.

The guide uses simple language and teaches in this order: **concepts first, then commands, then troubleshooting**.

## How the guide is organized

```
Foundations → System Administration → Networking → Security →
Automation → Infrastructure → Production Operations → Professional Practice
```

Each **part** is a folder. Each **chapter** is a folder inside the part. Each **topic** is its own Markdown file inside the chapter.

Start with [CONVENTIONS.md](CONVENTIONS.md) to learn how to read the examples.

## Who this guide is for

- Linux system administrators and SysAdmins
- DevOps and infrastructure engineers
- Advanced Linux users who want a structured reference

## Guide principles

01. Concepts are explained before commands.
02. Examples include expected output.
03. Important configuration files are explained.
04. Troubleshooting is included where it applies.
05. Distribution differences are labeled.
06. Commands that need root are marked.
07. Destructive commands are flagged with warnings.
08. Current, maintained tools are preferred over deprecated ones.
09. Links point to authoritative documentation.
10. Foundational and advanced material are kept separate.
